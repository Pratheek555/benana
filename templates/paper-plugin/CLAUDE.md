## Conventions

- Target Paper 1.21.4 (`paper-api 1.21.4-R0.1-SNAPSHOT`) and Java 21. No dependencies other than the Paper API.
- The main class is `dev.benana.mod.__NAME__` (see `plugin.yml`). Put additional classes in `dev.benana.mod`.
- Build with `mvn -q package`. The jar must end up at `target/__NAME__.jar`.
- Log meaningful actions with `getLogger().info(...)`. The playtester reads the server console.
- `playtest/` holds the test plan and verdicts from Benana's in-game playtester. Read it, but don't edit it.
- Don't commit; Benana commits each attempt.
